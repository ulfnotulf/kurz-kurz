Widget

Das „Geht heute kurz-kurz?“-Widget für den Android-Home-Bildschirm. Keine Gewährleistung, auf eigenes Risiko.

Android-Widget herunterladen (APK, 2,3 MB)

Installation

  • APK am Android-Gerät öffnen. Die Installation aus unbekannten Quellen muss einmalig erlaubt werden.
  • Lange auf eine freie Stelle am Home-Bildschirm drücken, „Widgets“ wählen und „Kurz-Kurz?“ hinzufügen.
  • Standort erlauben, damit das Widget das Wetter für deinen Ort zeigt.

iPhone?

Für das iPhone gibt es Kurz-Kurz inklusive Widget im App Store.
